# Fuuz LLM Skills

Claude skills for the [Fuuz Industrial Operations Platform](https://fuuz.com).

| Skill | Purpose |
|---|---|
| fuuz-data-flow | Design and build Fuuz data flows |
| fuuz-data-flow-nodes | Configure data flow node types |
| fuuz-data-model | Create and configure data models (ModelDefinition) |
| fuuz-expressions | JSONata expressions and JavaScript scripts |
| fuuz-graphql | GraphQL queries and mutations for the Fuuz API |
| fuuz-html-dashboards | HTML/data-URI dashboards rendered in Fuuz screens |
| fuuz-integration | Integration connectors ($integrate, REST, DB, FTP, Plex) |
| fuuz-screen-design | Screen structure, transforms, actions, patterns |
| fuuz-screen-elements | Screen element props and configuration |
| fuuz-screen-styling | Screen styling |

Each folder contains a `SKILL.md` plus supporting reference files.
